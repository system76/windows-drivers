## System76 machines with Intel Arrow Lake-HX CPUs

These drivers cover the following systems:

- Adder WS (addw5)
- Bonobo WS (bonw16)
- Serval WS (serw14)

### Drivers

- [Intel Chipset driver](./chipset-10.1.20062.8627.zip)
  - Download the ZIP file, extract, and run `SetupChipset.exe`
- [Intel SerialIO driver](./serialio-30.100.2419.23.zip)
  - Download the ZIP file, extract, and run `SetupSerialIO.exe`
- [Intel E3100 Ethernet driver](../lan/e3100-1.1.4.43.zip)
  - Download the ZIP file, extract, and run `SetupInf.exe`
- [Intel HID Driver](./hid-2.2.2.12.zip)
  - Download the ZIP file, extract, and run `SetupInf.exe`
- [Intel GNA driver](./gna-03.05.00.1578.zip)
  - Download the ZIP file, extract, and run `SetupInf.exe`
- [Intel NPU driver](./npu-32.0.100.3717.zip)
  - Download the ZIP file, extract, and run `SetupInf.exe`
- [Intel DTPF driver](./dptf-9.0.11905.54373.zip)
  - Download the ZIP file, extract, and run `SetupInf.exe`
